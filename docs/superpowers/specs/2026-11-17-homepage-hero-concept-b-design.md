# Homepage hero Concept B design

**Date:** 2026-11-17  
**Status:** Approved for implementation  
**Concept:** SAP → OpenText integration map (full-bleed)

## Copy

- Eyebrow: JS One · OpenText partner  
- Headline: Enterprise Information. Structured. Controlled. Transformed.  
- Supporting: A trusted OpenText implementation partner linking SAP processes to governed enterprise content. Founded 2006. Malaysia-based.  
- CTAs: Contact us (lime) · Explore Solutions (ghost)

## Composition

- Edge-to-edge hero stage with blueprint grid; no inset media card.  
- Desktop: type column left on solid `bg` scrim; map occupies right ~55–60% as the bleed plane.  
- Mobile: copy first, then stacked map (SAP → bridge → OpenText).  
- No legend chips, stats, or stickers on the art.  
- Header logo remains the dominant brand mark; no mark inside the SVG.

## SVG

- Triptych: SAP process cells | Integration spine | OpenText cells.  
- Hairline rects, orthogonal connectors, square terminals.  
- Labels from i18n; VIM called out on the accent bridge path.  
- Decorative (`aria-hidden`); theme via `--illust-*`.  
- Weight target ≤ ~18 KB gzipped; no photos in the LCP path.
